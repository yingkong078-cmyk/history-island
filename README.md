# 时光探险岛 · 初中历史 + 道德与法治

一个面向初中生的双学科趣味学习网页，参考「数学探险岛」的形式制作。内容覆盖**人教版（五·四学制）初中历史 6 册 + 道德与法治 4 册**：中国历史第一至第四册、世界历史第一至第二册，以及道法六年级全一册、七年级全一册、八年级上册、九年级上册。

## 打开方式

直接双击 `时光探险岛-中国历史.html`，用 Chrome / Edge / Safari 打开即可。所有页面、样式、脚本和人物图像都在这一个文件里，**基础学习功能不需要联网，也不需要安装任何东西**；AI 增强和联网搜索是可选项，需要网络。文件约 3.7—4MB，首次打开稍等一两秒。

也可以把 `index.html` 放到任意静态网站（GitHub Pages、Netlify、腾讯云静态托管等）上发布。学习记录保存在浏览器的 localStorage 中，换设备或清除浏览器数据会丢失；可在「成长档案」里导出 JSON 备份。

## 云端部署与跨设备同步

详细步骤见 **[云端部署与同步.md](云端部署与同步.md)**。

- **部署**：把 `云端部署包/index.html` 拖到 Netlify Drop，或上传到 GitHub Pages / 腾讯云静态托管，得到一个 https 网址。
- **同步**：网页右上角 ☁ → 云同步，选择「腾讯云开发（国内推荐）」或「Firebase（海外）」，填环境信息和一个家庭同步码；另外两台设备打开同一个网址，填同一套信息即可。
- **共享链接**：连接后点「复制共享链接」，发给家人；对方打开后点连接。
- **只同步学习进度**：XP、知识卡、答题、错题、徽章、成长星；姓名、笔记、照片不上传。
- 没有云账号时，仍可用「导出 / 导入学习记录」手动迁移。

> 云同步需要 https 公网地址；直接双击本地文件只能查看，不能连接云数据库。

历史课包含：核心结论、分点梳理、名词解释、重要人物、关键事件、条约/制度内容（如有）、历史意义、原始材料、记忆口诀、易混易错、前后联系、中考常考方向，并配 4 道左右分层练习。

道法课包含：生活化情境开场、核心观点、知识要点、关键词、2 个情境案例、可执行行动清单、法律依据、价值导向、情境材料、记忆口诀、易混易错、前后联系、中考常考方向，并配 4 道情境练习（选择、填空、排序、配对）。

## 学习角度

1. **知识梳理**：逐课知识卡，先读“是什么、为什么、有什么影响”。
2. **史料研读 / 情境探究**：历史读材料，道法读生活情境；都按“看来源—找关键词—联教材—辨立场/选做法”作答。
3. **时空坐标 / 行动清单**：历史把事件放回年代尺；道法把观点落到可执行的一周行动。
4. **跨课专题**：历史 14 个专题；道法有法律年龄线、情绪急救、交往边界、国家安全、答题模板等速查卡。
5. **闯关练习**：随机、每日、单元、单课、错题、情境/史料专项、排序配对、母题精练、由易到难、知识点专练十种模式。
6. **审题陪练**：每道题先给“题眼 + 三步审题”，答题后可复盘；可以点「🔊 读题」让小光读题干。
7. **成长与报告**：XP、等级、徽章、成长星、错题本、家长学习报告。

顶部可随时切换 **历史 / 道法**，两科共用进度、错题、XP 与云同步。历史有六个互动实验：时光轴推演、条约对比仪、历史地图推演、因果多米诺、近代化阶梯、人物档案馆。道法有「情境实验室」：朋友抄作业、网络谣言、亲子隐私、值日冲突、起外号、军事管理区拍照等 6 个两难情境，先选做法，再看后果和教材依据。

## 小光 · 学习小助手

右下角的小光是一个可发音的学习搭档：

- **会读**：用浏览器语音朗读题目、解析和知识卡，适合听题、跟读。
- **会找**：全站搜索单元、课时、名词、人物、事件、题目、专题、道法速查和年表；也可以从搜索框跳到 Bing 联网搜索。
- **会提醒**：默认连续使用 40 分钟提醒休息，可在设置里改成 20 / 30 / 40 / 45 / 60 分钟；提醒会读出来。
- **可拖动 / 半隐藏**：按住小光本体，或按住面板顶部的 ⠿ 标题栏，就能拖到屏幕任意位置；鼠标/手指移出小光也不会断。拖到左右边缘会自动贴边半隐藏，贴边状态下也能直接拖出来；点 ◧ 或边缘的小头像可以叫回来，设置里可重置位置。
- **会陪审题**：在闯关页问“帮我审题”，小光只给题眼和步骤，不直接替孩子选答案。
- **可选 AI**：在设置里填写 OpenAI 兼容接口地址、模型和 API Key 后，小光可以回答更开放的问题；不填也能用本地知识库。Key 只保存在本机浏览器，不随学习记录同步。

> 浏览器直连接口可能被 CORS 拦截；如遇到，填写自己的代理地址。AI 回答仅作学习辅助，不替代教材和老师。

人物档案馆收录 366 条人物 / 群像条目，其中 **235 条配有可靠历史图像**：照片、历史画像、雕像、壁画、钱币或书法。其余 131 条明确标注“暂无可靠画像”，**不使用想象出来的脸**。每张图在人物详情里给出图像类型、许可和来源链接（主要来自维基共享资源）。古代人物多为后世画像，页面会标注“非同时代”；雕像、书法、壁画等标注为“文物”，不冒充照片。

> 图像来源与许可：维基共享资源（Wikimedia Commons）。多为公有领域，少数为 CC BY / CC BY-SA / CC0；人物详情里逐张标注作者、许可与原始文件链接。若某张图需要替换或下架，删除 `src/data/portraits.json` 中对应条目并重新构建即可。

## 分册与课序说明

- 中国历史第一、二、三册的单元与课时目录，按 2024/2025 年统编新教材整理；第三册沿用原站的 26 课结构。
- 第四册按“成立和巩固—制度建立与探索—中国特色社会主义道路—民族团结与祖国统一—国防外交—科技文化与社会生活”六个单元编排，覆盖 2025 年新教材的主要知识点。
- 世界历史第一、二册按统编版世界历史上下册的单元结构整理。
- 道法六年级全一册对应“成长的节拍、友谊的天空、师长情谊、生命的思考”；七年级全一册对应“青春时光、做情绪情感的主人、在集体中成长、走进法治天地”；八年级上册对应“走进社会生活、遵守社会规则、承担社会责任、维护国家利益”；九年级上册对应“富强与创新、民主与法治、文明与家园、和谐与梦想”。
- 不同印次、不同地区的教材课序可能略有差异；本页以**知识点全覆盖**为目标，单元与课时名以现行统编教材的通行表述为准。

## 修改与维护

源文件在 `src/` 下，数据与界面分离：

- `src/data/toc.json`：六册历史总目录（单元/课时清单）
- `src/data/units.js`、`lessons-*.js`：中国近代史 26 课（原有内容）
- `src/data/generated/*.json`：新增 5 册历史 103 课的知识卡、题库、年表
- `src/data/dao-generated/*.json`：道德与法治 4 册 38 课的知识卡、情境与题库
- `src/data/dao-volumes.js`：学科定义与道法四册元数据
- `src/data/topics.js`、`topics-extra.js`：14 个历史跨课专题
- `src/data/timeline.js`：中国近代史年表
- `src/data/portraits.json`、`portraits/*.webp`：人物图像与出处
- `src/app/*.js`：状态、路由、页面、互动实验
- `src/style.css`：视觉系统

修改后运行：

```bash
node verify.mjs   # 校验历史数据
node build.mjs    # 生成单文件 HTML 与 index.html
```

> 说明：教材单元、课时目录、重要时间与结论依据统编教材及通行历史叙述整理；页面中的拓展解读、口诀、学习建议与练习题为本页原创，用于帮助理解，不替代教材原文。历史人物与事件评价请结合教材观点和课堂讲解；道法情境为教学示例，具体法律问题请以现行法律和学校、家长意见为准。
